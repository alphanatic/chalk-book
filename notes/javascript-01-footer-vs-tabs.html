Footer Links & Tabs

Same .map() pattern, a different job

Added a footer and a Backlog page to the React todo app, then compared Footer.jsx with Tabs.jsx. Both turn a list into elements with .map(). The tabs change state; the footer navigates through the URL.

The Backlog page holds 12 graded JavaScript fixes from the code review, each one to write by hand.

Two ways a click changes the page

ConceptTabs change state directly

Click "Open"→setSelectedTab('Open')→App re-renders→TodoList filters

ConceptThe footer goes through the URL

Click "Backlog"→URL ends in #backlog→hashchange event→setPage(hash)→App renders Backlog
Concept · Buttons act, links go. A button runs code on this page. A link goes somewhere: the URL changes, so Back works and the page can be bookmarked.

Gotcha · Home has two URLs: no hash at all ('') and '#'. A plain href === page misses the first, so Home needs its own rule.
Concept · aria-current="page" tells screen readers "you are here", and CSS can target it too: .main-footer-btn[aria-current]. A class name only means something to CSS.
Gotcha · On a page switched by the hash, an in-page link like <a href="#todo-ids"> changes the hash and leaves the page. The Backlog overview stops that with e.preventDefault() and scrolls with scrollIntoView() instead.

Bugs hit & fixed

Bug · footer links off centre

CAUSE
fanta.css gives every ul padding-left: 1rem. The footer's .main-footer ul rule didn't set padding, so that rule still applied. Caught while reading FantaCSS.
FIX
Set the padding in the more specific rule; .main-footer ul beats plain ul.
src/index.css
.main-footer ul {
  padding: 0;
}

Bug · apostrophe in JSX text

CAUSE
"you're" written as plain text inside JSX in Backlog.jsx. ESLint: `'` can be escaped with `&apos;`, `&lsquo;`, `&#39;`, `&rsquo;` react/no-unescaped-entities
FIX
Reworded to "you are". &apos; would work too. Apostrophes inside JavaScript strings are fine.

Best practices

Keys from the dataUse a value that belongs to the item, like a label or an id, not its position.
Buttons act, links go<button> for actions on this page, <a href> to go somewhere.
Clean up listenersReturn a function from useEffect that removes what it added.
One owner per stateApp owns page; the footer only reads it.
