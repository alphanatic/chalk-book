Full command sequence

LocalBack up, then rename the folder

B=../pokedex-backups/2026-10-13-personal-notes   # backup folder, outside the repo
mkdir -p $B                                      # -p: create parents, no error if it exists
cp -a personal-notes $B/                         # -a: keep dates and permissions
mv personal-notes .prog                          # leading dot: hidden from plain ls

LocalKeep it out of git under its new name

sed -i 's#^personal-notes/$#.prog/#' .git/info/exclude   # -i: edit in place
tail -2 .git/info/exclude                                # check the rule now reads .prog/
git status --short                                       # empty: .prog/ is not seen as new
.git/info/exclude (last lines)
# personal notes: kept on this machine only, never committed
.prog/
Concept · .git/info/exclude works like .gitignore, but it lives inside .git/ and is never committed. A public repo doesn't even reveal that the folder exists.

LocalFind every old reference

grep -rn "personal-notes" <memory-dir> .prog          # -r: recursive, -n: line numbers
sed -i 's#personal-notes/#.prog/#g' <memory-files>    # g: every match on a line
Gotcha · back up first, even for a plain rename. And the first grep found one more file than expected (pokemon-world-style.md). Always grep again after a rename before calling it done.

LocalScan and commit the story

git config user.email                      # confirm the repo's noreply identity
grep -nEi "/home/|claude.ai" story.md      # -E: extended regex, -i: any case; none = clean
git add story.md                           # stage only the new file
git commit -F -                            # -F -: message from stdin (a heredoc)
