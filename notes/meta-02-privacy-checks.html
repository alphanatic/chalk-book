LocalSwap text inside a PDF (one-off recipe)

python3 -m venv ~/venv-pdf && ~/venv-pdf/bin/pip install pymupdf fonttools brotli
~/venv-pdf/bin/python -c "from fontTools.ttLib import TTFont  # woff2 → ttf for PyMuPDF
f = TTFont('inter.woff2'); f.flavor = None; f.save('Inter.ttf')"
for page in doc:                                         # doc = pymupdf.open(path)
    for r in page.search_for(old):                       # every spot the text appears
        page.add_redact_annot(r, fill=bg)                # bg: colour sampled beside the text
    page.apply_redactions(images=0, graphics=0)          # remove the text, keep chips and lines
    page.insert_text((r.x0, span_baseline), new, fontsize=span_size,
                     fontfile="DejaVuSansMono.ttf", color=span_colour)   # same font, size, colour
doc.save(tmp, garbage=4, deflate=True)                   # garbage=4: drop the old text objects
diff <(pdftotext -layout before.pdf -) <(pdftotext -layout after.pdf -)    # only the swap differs

Workflow rules

Bugs hit & fixed

Bug · check.sh printed problems but said "all checks passed"

CAUSE
grep … | report runs report in a subshell. Its problems=$((problems+1)) was lost when the pipe ended.
FIX
Count failures in a file instead, and read the count at the end.
fail() { echo "  $1"; echo x >> "$tmp/problems"; }                    # survives the subshell
problems=0; [ -f "$tmp/problems" ] && problems=$(wc -l < "$tmp/problems")

Bug · clean run exited 1 with no summary

CAUSE
cat missing-file | wc -l fails, and set -euo pipefail stops the script there.
FIX
Test that the file exists before counting (the line above).

Bug · swapped PDF text came out tiny, on grey boxes

CAUSE
The redaction's replacement text used a built-in PDF font at a fitted size, and the default fill was grey.
FIX
Restore the backups, redact with the sampled background colour, then draw the new text with insert_text in the original font file, size and colour.

Bug · check.sh flagged CLAUDE.md itself

CAUSE
The rule's own wording showed the forbidden pattern as an example.
FIX
Reworded it to "never a placeholder", so the repo never shows the pattern at all.

Bug · zsh: ==REAL not found

CAUSE
In zsh, a word starting with = expands to a command's path, so echo ===REAL fails.
FIX
Quote it, echo "===REAL", or use another marker.
Gotcha · Claude Code blocks an AI from editing session transcripts. To scrub a word from ~/.claude/projects/, close every session and run the replacement yourself in a terminal.
