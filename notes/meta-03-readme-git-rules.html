README.md
# Chalk Book

A personal technical chalk book: one calm, skimmable note per topic, distilled from
work sessions with an AI so it can be repeated cold months later.

## View

Open `index.html` in a browser. No build step, no server. Any note can be saved as PDF
from the site's Export menu.

## Add a note

In any Claude Code session, say "chalk that up" (the `memory-dump` skill).

## Rules

How notes are named, written, styled and checked is all in [CLAUDE.md](CLAUDE.md).
A readable copy is the guide note, `notes/00-chalk-book-guide.html`.
Best practice · The README links to the rules instead of repeating them, so it can't drift. A site link and a licence line wait for backlog items 3 and 5.

LocalRelabel an unpushed commit, then push

git log --oneline -2                    # check the commit to relabel is the latest one
git stash                               # park uncommitted changes so the amend leaves them out
git commit --amend -m "README & ..."   # --amend: replace the latest commit
git stash pop                           # bring the parked changes back
git status -sb                          # -s: short, -b: branch line, shows "ahead 3"
git push                                # only after the user asked for it

Bugs hit & fixed

Bug · "Don't commit" taken literally

CAUSE
"I do not want you to commit anything any more" was read as "never commit". It could also mean "never push" or "ask first".
FIX
Offered three options with a line each. The answer was ask before each commit. The Git wording rule now makes asking the default for unclear git requests.

Bug · Personal git habits in the repo

CAUSE
CLAUDE.md, the skill and the guide all said "commit locally, push only when asked". That is one person's habit, and it bound anyone else who works on the repo.
FIX
The repo now only says to follow the user's own preferences. The habit itself moved to the global ~/.claude/CLAUDE.md.

Bug · Message style read as design

CAUSE
"Like my note titles" was turned into Title Case, & joins and a word count.
FIX
It means only: key words that best capture the content. Anything unstated follows the user's preferences first, Claude's defaults second.
