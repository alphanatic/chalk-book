Bugs hit & fixed

Bug · grep with a context window failed

CAUSE
grep -o ".\{0,90\}word.\{0,90\}" runs as ugrep here. On UTF-8 text it stops with ugrep: error: error at position 83 … exceeds complexity limits.
FIX
Strip the tags in Python and slice the text around each match instead.
python3 -c '...re.sub(r"<[^>]+>", " ", s)...'   # tags out, then slice around each hit

Bug · The pasted brief arrived cut short

CAUSE
The paste ended at step 8, so the constraints never arrived. One of them said: if a fix makes the file grow, propose shorter wording. Change 5 added 210 bytes without that offer.
FIX
Spotted from a screenshot of the full brief and reported against each constraint. Nothing else was broken: chalk-pastel.css, other notes and archive/ stayed untouched.

Bug · Stale git step in the backlog

CAUSE
The backlog's "how to work this list" still said "One commit per item … Push only when the user says so", after the git rules changed.
FIX
It now says never commit .prog/, and any other git step follows the user's own preferences.
